# Documentation Review Prompt

Use this prompt when asking an AI assistant to review a Sparki document.

## Constitutional Authority

This prompt inherits from the [Product Constitution](../blueprint/00-product-constitution.md). If the prompt conflicts with the Constitution, the Constitution governs.

## Prompt

First read the Product Constitution. Then review this document for clarity, durability, and alignment with the Constitution.

Do not invent missing facts. Separate your response into:

- Strengths
- Risks
- Missing decisions
- Open questions
- Suggested edits
- Constitutional conflicts
- TODOs for future constitutional inheritance

## Notes

Use this prompt before promoting a document from `Draft` to `Active`.
